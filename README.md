# Multi-Class Chest X-Ray Diagnosis with Grad-CAM

![Dataset](https://img.shields.io/badge/Dataset-NIH%20ChestX--ray14-darkgreen?style=for-the-badge)

## Executive Summary
Multi-class pulmonary radiography network classifying 4 chest X-ray conditions: **Normal, Viral/Bacterial Pneumonia, COVID-19 Pulmonary Opacity, Tuberculosis**.

---

## Highlights
- **Architecture**: DenseNet / ConvNet backbone.
- **Explainability**: Grad-CAM opacity heatmaps directly on chest radiographs.
- **Diagnostics**: 4x4 confusion matrix and per-disease ROC curves.

---
